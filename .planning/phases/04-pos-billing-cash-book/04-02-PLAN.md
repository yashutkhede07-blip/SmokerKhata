# Plan 04-02: Atomic Stock Decrement, Double-Sale Prevention & Offline Sync Replay

## Objective
Ensure bill creation and stock decrement run inside one atomic database transaction (`transaction.atomic()`) with `select_for_update()` row-level locks on sold items (BILL-09). Ensure replaying a bill with the same `(shop, bill_number)` idempotently returns the existing bill without duplicate stock deductions (BILL-08).

## Artifacts this phase produces
- Classes: `BillingService`
- Methods: `BillingService.create_bill_atomic()`
