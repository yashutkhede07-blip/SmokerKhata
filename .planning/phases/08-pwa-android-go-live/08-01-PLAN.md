# Plan 08-01: Frontend Architecture, Design Tokens, Routing & Offline Storage

## Goal
Scaffold the frontend monorepo workspace in `frontend/`:
- React 18 + TypeScript + Vite + Tailwind CSS (`PWA-01`).
- Grayscale design tokens with Light, Dark, System themes via CSS variables (`PWA-05`, `PWA-06`).
- i18next bilingual English + Hindi support (`PWA-07`).
- Offline-first IndexedDB schema via Dexie.js for bills, items, ledgers, and outbox operations (`PWA-03`).
- Service Worker registration & PWA manifest (`PWA-02`).
- React Router configuration for all 10 application routes (`PWA-10`).
- Configure Vite build output to `backend/static_pwa/` with Whitenoise single-deployable unit support (`PWA-04`).

## Requirements Covered
- **PWA-01**: React 18 + TS + Vite + Tailwind setup.
- **PWA-02**: Service worker and manifest.
- **PWA-03**: Dexie.js IndexedDB storage.
- **PWA-04**: Build output to static served by Whitenoise.
- **PWA-05**: Light, Dark, System theme toggle.
- **PWA-06**: Strict grayscale WCAG AA design tokens.
- **PWA-07**: Hindi and English translation setup.

## Tasks
1. Initialize Vite project in `frontend/` with React, TypeScript, and Tailwind CSS.
2. Setup Tailwind CSS with grayscale tokens (`bg-background`, `text-foreground`, `border-border`, etc.) and dark mode class.
3. Configure `i18n.ts` with English and Hindi translation dictionaries.
4. Define Dexie.js database schema in `src/db/index.ts` (`items`, `bills`, `customers`, `outbox`).
5. Configure `vite-plugin-pwa` or custom service worker and web manifest.
6. Configure `vite.config.ts` build outDir to `../backend/static_pwa`.

## Verification
- Run `npm run build` in `frontend/` and verify static files are emitted cleanly to `backend/static_pwa/`.
