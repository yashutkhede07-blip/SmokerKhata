# Plan 08-02: Complete 10-Screen PWA Implementation

## Goal
Implement the complete responsive UI adhering to Indian retail requirements:
- Touch targets >= 44px, POS action buttons >= 56px (`PWA-08`).
- All 10 screens (`PWA-10`):
  1. **Login**: Phone number entry, 6-digit OTP input, resend timer, token storage.
  2. **Dashboard**: Today's total sales, cash in drawer, total udhaar outstanding, low-stock count, quick navigation cards.
  3. **POS Billing**: Search bar, quick-add item grid, item quantity adjustment, payment mode selector (Cash, UPI, Udhaar, Split), bill completion modal with WhatsApp receipt share link.
  4. **Customer Ledger**: Customers list sorted by highest outstanding balance, detail ledger view with running balance, WhatsApp reminder trigger.
  5. **Item Master**: Category filter tabs, item cards with prices and cost, variant list, active/inactive toggle.
  6. **Stock Management**: Current stock levels, low-stock threshold warning badge, quick stock adjustment.
  7. **Cash Book**: Daily opening cash, record cash-in / cash-out, dynamic expected closing calculation, physical closing count with mismatch flagging.
  8. **Reports**: Date range selector, gross profit & sales breakdown, one-click Excel (.xlsx) and PDF download triggers.
  9. **Settings**: Shop details, staff list with roles, language switcher (Hindi / English), theme selector (Light / Dark / System), subscription status & plan info.
  10. **Sync Indicator**: Header status banner ("Synced", "N pending", "Offline", "Sync error") connected to Dexie outbox queue and network status.

## Requirements Covered
- **PWA-08**: Minimum touch target sizing (44px/56px).
- **PWA-09**: Lightweight components optimized for 3G performance.
- **PWA-10**: Full 10 screens implementation.

## Tasks
1. Build reusable UI components (Button, Input, Card, Modal, Badge, Header with Sync Indicator).
2. Implement 10 route components under `src/pages/`.
3. Connect API services using `fetch` / `axios` with automatic offline Dexie.js fallback.
4. Verify all components support both English and Hindi localization strings.

## Verification
- Verify all routes mount and render without React runtime errors.
- Run frontend type check (`tsc --noEmit`).
