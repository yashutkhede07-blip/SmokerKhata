# Phase 6 Research: Reports & Audit Log

## Domain & Architectural Context

### 1. Requirements Overview
- **REPT-01**: Daily, weekly, and monthly sales and profit summary report.
- **REPT-02**: Top-selling items report with quantity and revenue.
- **REPT-03**: Margin per item report (selling price minus cost price).
- **REPT-04**: Reports exportable as Excel (.xlsx) using `openpyxl`.
- **REPT-05**: Reports exportable as PDF using `ReportLab` (pure python, no system dependencies).
- **REPT-06**: Large date-range exports generated by `django-q2` background jobs.
- **AUDT-01**: Create, update, delete operations record user, UTC timestamp, old value, and new value.
- **AUDT-02**: Soft-delete only (`deleted_at`); no hard deletion in business logic.
- **AUDT-03**: Audit log entries are immutable and append-only.
- **AUDT-04**: Conflict resolution losing version is preserved in audit log.

### 2. Money & Format Constraints
- All amounts internally represented as integer paise (`BigIntegerField`).
- In exports and responses:
  - Total sales, total cost, gross profit in paise, formatted in ₹ with lakh formatting (e.g. ₹1,25,000.00).
  - Dates formatted as `DD/MM/YYYY`.

### 3. Architecture Design
- **Audit Log App (`backend/audit/`):**
  - Model: `AuditLogEntry(id, shop, user, model_name, record_id, action, old_values, new_values, created_at)`
  - Signals / service hooks attached to business models (`Item`, `Category`, `Customer`, `Supplier`, `Bill`, `CashBookDay`).
  - Strict immutability (`save()` and `delete()` blocked on existing records).
  - Viewset/endpoint with owner/manager access only (`IsShopManagerOrOwner`).
- **Reports App (`backend/reports/`):**
  - Models: `ReportRequest(id, shop, report_type, date_from, date_to, status, file_format, file_path, created_by, created_at, completed_at)`
  - Calculation Service:
    - Summary calculations from `Bill` and `BillItem` (`total_sales_paise`, `total_cost_paise`, `gross_profit_paise`).
    - Top items aggregation (`item_name`, `quantity`, `revenue_paise`).
    - Item margin analysis (`Item.selling_price_paise - Item.cost_price_paise`).
  - Export Service:
    - Excel generation using `openpyxl` with styled headers and Indian currency formatting.
    - PDF generation using `reportlab.platypus` (SimpleDocTemplate, Table, Paragraph) with clean invoice/report layout.
  - Background Task:
    - If date range > 7 days, trigger async task via `django_q.tasks.async_task` and return report status "PENDING" / "GENERATING".
    - Direct download endpoint `/api/reports/requests/{id}/download/`.
