# Plan 06-03: Export Engine (Excel & PDF) & Background Task Workers

## Goal
Implement document generation and asynchronous reporting export:
- Formatted Excel export (.xlsx) via `openpyxl` with styled headers, DD/MM/YYYY dates, and Indian currency lakh formatting (`REPT-04`).
- Printable PDF report via `ReportLab` (pure python Platypus tables/styles) with shop header and summary blocks (`REPT-05`).
- `ReportRequest` model tracking background export job status ("PENDING", "PROCESSING", "READY", "FAILED") with django-q2 (`REPT-06`).
- Secure file download endpoint.

## Requirements Covered
- **REPT-04**: Excel export with openpyxl.
- **REPT-05**: PDF export with ReportLab.
- **REPT-06**: Large range background generation via django-q2 with download URL.

## Tasks
1. Define `ReportRequest` model in `reports`:
   - `id`, `shop`, `report_type`, `format` (`XLSX`, `PDF`), `date_from`, `date_to`, `status`, `file`, `created_by`, `created_at`, `completed_at`.
2. Implement `ExcelReportGenerator`:
   - Generates workbook with summary sheet and itemized breakdown.
   - Formats numbers in ₹ (with Indian comma grouping).
3. Implement `PdfReportGenerator`:
   - Uses `SimpleDocTemplate`, `Table`, `Paragraph`, `getSampleStyleSheet`.
   - Produces clean, print-ready PDF.
4. Implement `generate_report_task(request_id)` for django-q2 asynchronous execution.
5. Create export endpoints:
   - `POST /api/reports/export/` (initiates sync or async export).
   - `GET /api/reports/requests/{id}/` (checks status).
   - `GET /api/reports/requests/{id}/download/` (serves generated document).
6. Build comprehensive test suite `backend/tests/test_reports.py`.

## Verification
- Unit test verifying valid .xlsx output with openpyxl.
- Unit test verifying valid .pdf output with ReportLab.
- End-to-end test of export request and download.
