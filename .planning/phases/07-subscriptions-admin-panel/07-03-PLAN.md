# Plan 07-03: Django Admin Customization & Plan Feature Flags

## Goal
Customize the Django admin interface for enterprise back-office management:
- Display shop MRR, current plan, status badges (TRIAL, ACTIVE, GRACE, EXPIRED), and churn risk in `ShopAdmin` (`ADMN-01`).
- Custom admin action to extend trial or subscription duration with a **mandatory reason note** recorded in `AuditLogEntry` (`ADMN-02`).
- `FeatureFlag` model attached to plans to configure feature toggles from Django admin (`ADMN-03`).
- Full test suite `backend/tests/test_subscriptions.py`.

## Requirements Covered
- **ADMN-01**: Admin visibility for MRR, subscriptions, and churn.
- **ADMN-02**: Trial extension admin action with mandatory reason note logged to audit trail.
- **ADMN-03**: Feature flags per plan configurable in Django admin.

## Tasks
1. Define `FeatureFlag` model in `subscriptions/models.py`.
2. Configure `admin.py` for `subscriptions` and `shops`:
   - Add MRR calculation property to `Shop`.
   - Add custom form / action in Django admin for trial extensions prompting for a reason note.
   - Automatically call `AuditService.record_audit` when an admin extends a trial.
3. Build comprehensive test suite `backend/tests/test_subscriptions.py`.
4. Run full pytest suite to verify zero regressions.

## Verification
- Unit test ensuring trial extension action creates an AuditLogEntry with the admin user and reason.
- Unit test verifying MRR calculation and plan feature flag evaluation.
