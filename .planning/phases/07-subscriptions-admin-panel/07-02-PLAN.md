# Plan 07-02: Payment Gateways (Razorpay Webhook & Google Play Verification)

## Goal
Implement payment provider integrations for Web and Android clients:
- Razorpay Subscriptions webhook endpoint `/api/subscriptions/webhook/razorpay/`:
  - HMAC-SHA256 signature verification (`X-Razorpay-Signature`).
  - Store raw webhook in `SubscriptionEvent` first.
  - Process subscription activation / renewal idempotently (`SUBS-05`).
- Google Play Billing verification endpoint `/api/subscriptions/play-billing/verify/`:
  - Verify purchase token against Google Play Developer API (or test mock) (`SUBS-06`).
  - Activate subscription atomically.
- Prorated plan upgrade / downgrade calculator (`SUBS-10`).

## Requirements Covered
- **SUBS-04**: Razorpay & Play Billing payment paths.
- **SUBS-05**: Razorpay webhook verification and idempotent event handler.
- **SUBS-06**: Google Play Billing token verification.
- **SUBS-10**: Prorated upgrade/downgrade logic.

## Tasks
1. Implement `RazorpayWebhookView` with HMAC verification and idempotency check.
2. Implement `PlayBillingVerificationView` validating purchase tokens.
3. Implement `ProrationService` calculating credit balances for unused plan periods.
4. Add client endpoints to view current plans, active subscription status, and upgrade previews.

## Verification
- Unit test verifying valid Razorpay signature activates subscription.
- Unit test verifying invalid signature returns 400.
- Unit test ensuring replaying the same webhook event is idempotent.
- Unit test verifying Google Play purchase token verification.
