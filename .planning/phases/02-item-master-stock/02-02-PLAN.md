# Plan 02-02: Stock Ledger, Movements, and Balance Computation

## Objective
Implement immutable `StockLedgerEntry` model and service layer for recording stock changes (purchases, adjustments, sales). Ensure stock changes are strictly append-only ledger entries (STCK-03) and never direct column modifications.

## Artifacts this phase produces
- Classes: `StockLedgerEntry`, `StockLedgerSerializer`, `StockAdjustmentSerializer`, `StockService`
- Endpoints:
  - `POST /api/inventory/stock/adjust/`
  - `GET /api/inventory/stock/ledger/?item_id={id}`
  - `GET /api/inventory/items/{id}/stock/`
