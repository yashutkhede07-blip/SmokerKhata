# Plan 02-03: Low-Stock Alerts, Dead-Stock Reports, and Role Restrictions

## Objective
Implement low-stock threshold queries (STCK-04) and dead-stock reporting (STCK-05 - items with zero movement in N days). Restrict stock adjustments and price edits to Owner and Manager roles.

## Artifacts this phase produces
- Classes: `LowStockView`, `DeadStockReportView`, `IsInventoryManagerOrOwner`
- Endpoints:
  - `GET /api/inventory/alerts/low-stock/`
  - `GET /api/inventory/reports/dead-stock/?days=30`

## Tasks

<task id="02-03-01">
  <read_first>
    - backend/inventory/models.py
    - backend/inventory/services.py
  </read_first>
  <action>
    Implement queries in backend/inventory/reports.py:
    1. Low-stock: filter items where current aggregate stock <= item.low_stock_threshold and item.is_active is True.
    2. Dead-stock: filter items where latest StockLedgerEntry.created_at < now - N days (default 30 days) or no entries exist.
    Expose via dedicated API endpoints with sorting.
  </action>
  <acceptance_criteria>
    - GET /api/inventory/alerts/low-stock/ returns list of items below threshold
    - GET /api/inventory/reports/dead-stock/?days=30 returns items with no activity in 30 days
  </acceptance_criteria>
  <verify>
    <automated>pytest backend/tests/test_stock_reports.py</automated>
    <fails_when>non-zero exit</fails_when>
  </verify>
</task>

<task id="02-03-02">
  <read_first>
    - backend/shops/permissions.py
    - backend/inventory/views.py
  </read_first>
  <action>
    Enforce permission checks across all inventory endpoints:
    - View items/categories/stock: IsShopMember (Owner, Manager, Cashier can read)
    - Create/Update/Delete items or categories: IsShopManagerOrOwner
    - Adjust stock: IsShopManagerOrOwner
    Cashier attempting POST/PUT/DELETE receives HTTP 403 Forbidden.
  </action>
  <acceptance_criteria>
    - Cashier can read item catalogue but gets 403 on item creation or stock adjustment
    - Owner and Manager can execute adjustments and item modifications
  </acceptance_criteria>
  <verify>
    <automated>pytest backend/tests/test_inventory_permissions.py</automated>
    <fails_when>non-zero exit</fails_when>
  </verify>
</task>
