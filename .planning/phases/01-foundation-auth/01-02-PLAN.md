| Boundary | Description |
|----------|-------------|
| Client → OTP Endpoint | Public endpoint subject to SMS flooding and brute force |
| Client → Protected API | JWT bearer token verified for identity and role |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-02 | Denial of Service | POST /api/auth/otp/send | high | mitigate | Rate limit to 5 attempts per 10 minutes per phone/IP via database cache |
| T-01-03 | Spoofing | POST /api/auth/otp/verify | high | mitigate | Max 3 incorrect verification attempts locks OTP; 5-minute expiration |
| T-01-04 | Elevation of Privilege | DRF Endpoints | high | mitigate | Role-based permission classes enforce shop membership and cashier restrictions on every route |
</threat_model>
